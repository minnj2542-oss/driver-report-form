# 크롬 확장프로그램 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력해서 이동
2. 오른쪽 위 **"개발자 모드"** 켜기
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 `chrome-extension` 폴더를 선택

설치되면 크롬 툴바에 파란 느낌표(!) 아이콘이 생깁니다.

- 아이콘 클릭 → 대기중인 신고 목록이 작은 팝업으로 뜸 (복사 / 처리완료 버튼 포함)
- 대기중인 신고가 있으면 아이콘 위에 빨간 배지로 개수가 항상 표시됨 (1분마다 자동 확인)
- 팝업을 열지 않아도 배지 숫자만으로 새 신고 여부를 바로 알 수 있음

## 참고
- 코드/디자인을 바꾸면 `chrome://extensions`에서 이 확장프로그램의 새로고침 아이콘을 눌러야 반영됩니다.
- 다른 컴퓨터에도 설치하려면 이 `chrome-extension` 폴더를 복사해서 위 방법을 그대로 반복하면 됩니다 (Chrome 웹스토어 등록 없이 사내용으로만 사용 가능).
